# 口径：每个数字怎么算出来的

指标只要换一种切分或分母，结论就可能反过来。这一页把口径写死，方便复算和争论。

## 切分

**正文**：Markdown 的标题、列表项、引用行、表格行不进正文统计。代码块、行内代码、URL、HTML 标签、YAML front matter 用等长空格屏蔽，字符偏移不变，所以示例仍能定位到原句。

**段落**：空行分段。同一段内的换行，如果上一行没有以 `。！？!?…` 结尾，视为软换行，合并成一段；否则视为新段。这样同时兼容「一行一段」和「按宽度折行」两种写法。

**句子**：以 `。！？!?…` 切分，连续标点和后置引号并入前句。只保留含两个以上汉字的片段。

**分句**：以 `，,；;：:` 切分。

**字数**：只数汉字（`\u4e00-\u9fff`），不含标点、空格、数字和英文。

## 密度与分母

| 指标类型 | 分母 | 说明 |
|---|---|---|
| 句式命中 | 正文汉字数 | 换算成每千字 |
| 同义轮换 | 正文段数 | 换算成每段 |
| 小标题密度 | 正文汉字数 | 每千字几个 |
| 段间连环 | 段数 | 用最长连续段数判定 |

两个必须记住的陷阱：

1. **结构元素要用同类元素做分母。** 问句小标题按每千字算是人类的 32 倍，按「占小标题总数」算只有 0.75 倍。前者测的是「AI 小标题多」，后者才是「AI 爱用问句当标题」。
2. **字少了，密度会自己涨。** 本项目的示例改后少了 15% 的字，小标题还是 4 个，每千字密度从 6.03 升到 7.09。这不是结构变碎，是分母变小。任何前后对比都要同时看绝对数和字数。

## 各项指标的定义

**翻案腔 / 对举**：匹配「不是……而是」「并非……而是」「不在于……而在于」「与其说……不如说」「看似……实则」「表面……实际」。中间允许跨逗号，不允许跨句号。

**提示语冒号**：冒号前 16 字内出现「一句话总结 / 核心是 / 关键是 / 本质是 / 原因如下 / 结论是 / 如下 / 两点 / 三点」等提示语。普通冒号、标题冒号、引出原话的冒号不计。

**过长前置定语**：「的」字前的修饰段（从上一个句读符号算起）超过 15 个汉字。修饰段内可以有顿号，因为带列举的长定语正是要抓的形态。

**顿号密集罗列**：一个分句内出现两个以上顿号，且切出的项不少于三个。

**话题壳与时间从句**：匹配「当……时，」「对于……来说，」「就……而言，」「在……方面，」。

**句首连接词**：句首（或上一句结束后）出现「然而、因此、此外、同时、另外、实际上、事实上、更重要的是、值得注意的是、需要指出的是、综上所述」并接逗号。

**相邻句骨架复刻**：把句子压成骨架——实词折成 `H`，疑问词折成 `W`，虚词（的了在是和与及或被把将从而就都也还又很更最不没着过吗呢吧啊之其者所）和标点保留。相邻两句骨架完全相同且各含 5 个以上汉字时计一组；连续三句相同记一个三连。

这个方法比「句长相近」严得多：长度巧合不会被误判成同构，但语义并列、字面不同的排比也抓不到。后者需要人读。

**段间衔接连环**：段落首句以「这也解释了、从这个角度、换句话说、更重要的是、正因为如此、这意味着、由此可见、基于此」等承接语开头。最长连续段数 ≥3 记为命中。

**同义轮换**：同一段内出现同一近义词组中的三个以上成员（如优化/增强/提升/提高/改善/强化）。这是词表近似，不是语义判断，只作弱信号。

**句长离散度**：句子汉字长度的变异系数（标准差/均值），少于 12 句不计算。同时报告 P10、P90、短句占比、长句占比、相邻句长差 ≤3 的比例。

**段落长度离散度**：段落汉字长度的变异系数，少于 4 段不计算。

**小标题切得过碎**：小标题数/千字，以及各节汉字长度的变异系数、每节中位句数。

**词汇多样性**：字符级 MATTR-100，加二元组重复率。**不用 MTLD 原值**：没有分词时，二元组的 TTR 接近饱和，MTLD 会算出上千的失真值。字符 MATTR 有界、可比较，但绝对值不能和论文里的词级 MTLD 对标。

**破折号**：`——` 计一次，单独出现的 `—` 各计一次。

## 阈值

| 指标 | 门槛 |
|---|---|
| 翻案腔 | 0.3 次/千字 |
| 提示语冒号 | 0.2 次/千字 |
| 过长前置定语 | 0.3 次/千字 |
| 顿号密集罗列 | 2.0 次/千字 |
| 起手式 | 0.15 次/千字 |
| 话题壳 | 0.3 次/千字 |
| 句首连接词 | 1.0 次/千字 |
| 相邻句同构 | 0.5 次/千字 |
| 同义轮换 | 0.8 次/段 |
| 段间连环 | 最长连续 3 段 |
| 破折号 | 2.0 次/千字（指纹，不定罪） |

门槛的作用是排序，不是判决。低于门槛记为「观察」，表示有命中但不优先处理。零命中不等于文章写得好，只表示没有命中本工具能测的形态。

## 为什么不输出 AI 率

三个原因：

1. **没有可靠的本地分类器。** 本工具只做规则和统计，不做模型推断。任何「AI 概率 87%」都需要一个训练过的分类器，而分类器的跨文体、跨模型泛化很差。
2. **检测器本身不稳定。** 转述就能大幅降低检出率；非母语写作者被误判的比例过高。
3. **数字会诱导错误目标。** 一旦有了一个百分比，作者就会去优化那个百分比，而不是优化可读性。最后得到一篇专门对付检测器的文章，读起来更差。

所以本工具输出的是：命中了什么、在哪一句、密度多少、人类参照多少。判断留给作者。

## 复算

```bash
# 单篇报告
python -m zh_humanize.cli 稿件.md --md 报告.md

# 机器可读
python -m zh_humanize.cli 稿件.md --json > report.json

# 前后对比
python -m zh_humanize.cli --compare 原稿.md 改后.md

# 自检
python -m zh_humanize.cli --selftest
python -m unittest discover -s tests -t .
```

要复核效应量，需要自建对照语料：同一批事实、同一批话题，分别让目标模型写和人类写，按上面的切分与分母计算命中率，再做配对检验。本项目不附带语料（版权原因），但切分、正则、分母和门槛都在代码里，可以原样复算。
