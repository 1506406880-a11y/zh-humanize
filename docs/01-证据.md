# 证据：哪些特征真的站得住

这份项目的规则不是从「读着像 AI」的直觉里来的，也不是从词表里抄的。它只保留能在对照语料里重复出现、并且能指出「改哪一句」的特征。

## 两轮实测

| 轮次 | 设计 | 规模 |
|---|---|---|
| 第一轮 | 同批话题，5 个模型各写 60 篇，与人类作者文章对照 | AI 300 篇 / 人类 329 篇，约 280 万字 |
| 第二轮 | 把人类文章里的事实提炼成任务卡，让模型在同样事实约束下写同题文章 | 270 对配对，GPT 135 + Opus 135 |

第二轮的用意是排除话题混杂：如果 AI 写科技、人类写生活，任何词频差异都可能是话题造成的，不是模型造成的。配对之后仍然同向的特征，才留下。

判定用 Cliff's δ：随机抽一篇 AI 文和一篇人类文，「AI 更多」的概率减去「AI 更少」的概率。|δ| ≥ 0.33 记为显著。

数据与结论来自公开项目 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)（CC BY-NC 4.0）。本项目引用其效应量，代码与规则表为独立实现。

## A 级：两轮同向

| 特征 | 第一轮 | 配对复测 | 人类参考 |
|---|---|---|---|
| 翻案腔「不是 A 而是 B」 | 3.4 倍 | GPT δ+0.88 / Opus δ+0.72 | 0.22 次/千字 |
| 词汇过度多样（不敢重复） | — | MTLD +0.91/+0.55；MATTR +0.75/+0.55 | 人类更爱原词重用 |
| 小标题切得过碎 | 每篇中位 7 节 | 节长方差 −0.91/−0.75；密度 +0.65/+0.83 | 人类中位 1 节 |
| 过长前置定语 | 0.42 次/千字 | δ+0.48/+0.54 | 明显更低 |
| 结论提示冒号 | 3.8 倍 | 2.1 倍（冒号总量人类反而更多） | 0.08 次/千字 |
| 密集并列 / 顿号罗列 | 3.21 vs 1.78 | 1.45 倍 | 1.78 次/千字 |
| 段间衔接过顺 | — | 明确承接 98.9% vs 95.2%；跳转 2.1% vs 7.2% | 每 14 段跳一次 |

「词汇过度多样」这条与直觉相反：AI 不敢重复用词，同一段里「优化／增强／提升／提高」轮着换；人类会反复用同一个词。所以改法不是加生僻词，而是统一回原名。

## X 级：被实测推翻的流行规则

这一节是本项目与多数「去 AI 味」工具最大的分歧。下面每一条都有人写进词表或规则集，但在同题同事实的配对语料里站不住。

| 流行规则 | 实测结果 | 处置 |
|---|---|---|
| 赋能 / 闭环 / 抓手 / 底层逻辑 | δ+0.10，不显著 | 永不据此删改 |
| 首先 / 其次 / 总之 | δ+0.02 | 永不删 |
| 序数词小标题 | 方向反转：人类 8.6%，AI 4.9% | 永不改 |
| 「这意味着」 | 反向：人类 0.027，AI 0.016 次/千字 | 永不删 |
| 空转句引列表 | 反向：人类高一个量级 | 永不改 |
| 精确数字堆砌 | δ−0.06，配对后消失 | 不增不删 |
| 名词化、明喻、设问、模糊量词 | 全部 \|δ\|<0.2 | 不据此批量改 |
| 句长 / 段落长度不参差 | 两轮均无差异 | 不为节奏改句长 |
| 「其」字用量 | 人类更多 | 不删 |

## 四条方法学教训

**1. 单模型的癖好会被误读成 AI 的共性。** 早期只用两个模型，得出「破折号是 Claude 独有」；扩到五个模型后发现 DeepSeek 用得更多，而 GPT 的破折号比人类还少。任何「AI 都爱用 X」的说法，先问用了几个模型。

**2. 分母选错会给出反向结论。** 按每千字算，AI 的问句小标题是人类 32 倍；换成「占全部小标题的比例」，AI 2.7%，人类最高 3.6%，差异消失。前者测的是「AI 小标题本来就多」，不是「AI 爱用问句当标题」。结构类指标的分母必须是同类元素总数。

**3. 宽正则先造出假象，再被当成规律。** 早期「AI 句长均匀度是人类 50 倍」的结论，来自切句缺陷；修正切句后只有 0.87 倍。

**4. 先抽样看 20 条命中，再看频率。** 六次测量失误全部是「先看到数字、后看命中内容」造成的。频率只用来决定某个句式够不够格立为规则，不用来证明规则本身。

## 局限

- 语料因版权不公开，上述数字第三方无法直接核验。可复用的是切分规则、分母、判定门槛和正则，这些都在 `zh_humanize/` 里。
- 语义层判断由单模型完成，抽样复核误判率 15–30%。方向可信，精确百分点不可信。
- 人类语料组间差异很大（破折号极差可达百倍），扩充语料可能改变部分结论。
- 模型持续向人类文风收敛，所有频率都是特定时点的观测。
- 比喻是否贴切、案例是否凑数、论证是否成立，机器判不了，只能人审。
